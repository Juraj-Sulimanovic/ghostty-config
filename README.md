# ghostty config

Catppuccin Mocha on a pure black background. Every window runs `tmux-start` from [tmux-config](https://github.com/Juraj-Sulimanovic/tmux-config), so tmux owns all splits and tabs. Ghostty's own split keys are unbound.

```sh
git clone https://github.com/Juraj-Sulimanovic/ghostty-config ~/.config/ghostty
```

`Cmd+k` clears the tmux pane, `Ctrl+1..5` switch tmux windows (turn off macOS "Switch to Desktop" shortcuts), `Cmd+Left/Right/Backspace` edit the shell line.
